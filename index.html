Full stack web app

Job-Tag

A tracker for job applications with a calendar for interviews and deadlines, and file upload and download for resumes, CVs, and other documents. Paste a job posting link and it fills in the job title, company, work setup, and employment type by itself, so there is almost no manual encoding left per application.

Browser game

Byte: A Coding Pet

A virtual pet where every interaction has to be earned by solving a JavaScript challenge instead of clicking a button. It runs user submitted functions against test cases inside a contained scope and reports per test results, handling syntax and runtime errors without breaking the app. Game logic stays as plain JavaScript, separate from React state and UI.
