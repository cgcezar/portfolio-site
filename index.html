Things I built and shipped

Full stack web app

Job-Tag

A tracker for job applications with a calendar for interviews and deadlines, and file upload and download for resumes and CVs. Paste a LinkedIn job link and a serverless function parses it into job title, company, work setup, and employment type, so there is almost no manual encoding left. Runs on a GitHub Actions pipeline.

Live siteSource

Security tooling

netscan-reporter

Turns Nmap XML output into a readable HTML and CSV network inventory, then runs an audit pass that flags at risk services: plaintext protocols, exposed databases, and open remote access ports. Standard library only, so it runs anywhere Python does.

PythonNmapNo dependencies

Source

Security tooling

pcap-triage

A packet capture analyzer built on Scapy. It summarizes the protocol breakdown, top talkers, and DNS and HTTP activity, then flags cleartext credentials and possible port scans. Outputs JSON so it can sit inside a larger pipeline instead of only being read by a person.

PythonScapyJSON output

Source

Security tooling

passaudit

A defensive password policy auditor that scores entropy, checks breach list membership, and catches weak patterns. It includes a pure Python NTLM implementation for generating practice hashes and a dictionary attack demonstrator, so the cost of a weak policy is visible instead of theoretical.

PythonNTLMEntropy scoring

Source

Security tooling

HeaderHound

A passive Burp Suite extension written in Jython. It audits HTTP responses for missing security headers such as CSP, HSTS, and X-Frame-Options, and for headers that give away version information, then raises each finding with a severity and remediation guidance.

JythonBurp SuiteHTTP
